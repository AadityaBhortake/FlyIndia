## **Technical Information – Backend and Database**

### **Backend (Java Application Logic)**

* The backend of **FlyIndia** is developed using **Java**.
* It handles the core functionalities of the system such as:

  * User authentication
  * Flight searching
  * Ticket booking
  * Database operations
* **JDBC (Java Database Connectivity)** is used to establish communication between the Java application and the MySQL database.
* SQL queries are executed through Java code to retrieve and store data.
* The backend validates user inputs before processing requests.
* Exception handling mechanisms are implemented to manage runtime and database errors efficiently.
* Prepared statements are used for executing SQL queries securely and efficiently.

---

### **Database (MySQL)**

* The system uses **MySQL** as the relational database management system.
* The database stores:

  * User login credentials
  * Flight information
  * Passenger booking details
* The database is structured using multiple relational tables:

  * `user_login`
  * `flight`
  * `booking`
* Primary keys are used to uniquely identify records.
* Relationships between tables help maintain data consistency.
* SQL operations such as:

  * `SELECT`
  * `INSERT`
  * `UPDATE`
  * `DELETE`
    are used for managing records.
* Constraints and validations are applied to maintain data integrity.
* Prepared statements help protect the database from SQL injection attacks.
* The database ensures fast retrieval and secure storage of airline reservation data.
